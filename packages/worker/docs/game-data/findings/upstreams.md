## Additional repositories and search findings

- `4sval/FModel` is the upstream GUI/tooling project used by the two extraction workflows; its CUE4Parse support covers Unreal PAK/IO Store formats, but installed-game extraction was not tested on this Mac.
- `ClostroOffi/wuwa-aes-archive` and `yarik0chka/wuwa-keys` are key-discovery sources referenced by the extraction projects. AES keys are required for encrypted local resources.
- Searches for ConfigDB/datamine/dialogue/QuestId/flowstate/TextMap/cutscene/Sequence/Wwise surfaced the repositories above plus unrelated gacha/translation projects. No other verified 3.x quest-chronology parser was found in the inspected results.

## Reliability labels

- **Primary:** Arikatsu 3.6 for current public data; RealNath for transcript ordering/printing.
- **Secondary:** Dimbreath 3.1 for overlapping historical data; WutheringDialog for preserving action IDs and non-dialogue action rows.
- **Reference:** SunsetMkt cutscene/caption workflow and Ludiglot local extraction workflow.
- **Fallback candidate:** FModelCLI/FModel for re-extracting data when community datasets lag. Mac feasibility is not demonstrated by these runs.
